# Kharki Inventory Management System

A responsive inventory management portfolio website built with HTML, CSS, and vanilla JavaScript.

## Features
- Product dashboard: total products, inventory value, low-stock count, and sales count
- Create, view, edit, and delete products
- SKU uniqueness validation
- Low-stock and out-of-stock alerts
- Search and stock filters
- Record sales and deduct quantities automatically
- Recent sales table
- Export inventory to CSV
- Browser persistence with localStorage
- Responsive desktop and mobile layout


## Important limitations
This is a portfolio/demo application. Records are stored only in the current browser using localStorage; visitors do not share data across devices. Clearing browser data removes saved demo records. There is no login or server database. Do not use it as a production inventory system without a secure backend, access controls, and backups.
